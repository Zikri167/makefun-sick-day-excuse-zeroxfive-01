# The Funniest Sick-Day Excuse

Entry for the [make.fun bounty "The Funniest Sick-Day Excuse"](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) (sponsor Zero Five, $2 prize pool).

## What this program does

`main.ts` is a deterministic Node 22 stdlib-only program. It writes a single line — one funny sick-day excuse, 153 characters, no trailing newline — to `(MAKEFUN_OUTPUT_DIR || "/output")/entry.txt`. No network, no randomness: every run produces byte-identical output.

The entry:

> Morning, can't come in — a moth flew straight into my eye last night and it swelled shut, so now I look like I've been crying over the quarterly targets.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
